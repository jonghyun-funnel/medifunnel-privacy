퍼널커머스 AI 솔루션 개인정보 처리방침

원종현(이하 "운영자")은 크롬 확장 프로그램 「퍼널커머스 AI 솔루션」(이하 "확장")을 제공하면서 이용자의 정보를 아래와 같이 다룹니다.

시행일: 2026년 11월 24일 개정, 0.1.2 게시일부터 시행(2026년 12월 1일 이후). 이전 판은 16절 개정 이력.

1. 한눈에 보기

  • 본인 네이버 검색광고 키 없이 검색량을 볼 때에만, 조회하려는 검색어가 운영 서버로 전송됩니다(3절 (마)). 운영 서버는 운영자의 키로 네이버에 검색량을 대신 조회해 돌려줍니다. 설정에서 "키 없이 검색량 보기"를 끄거나 본인 키를 연결하면 검색어를 보내지 않습니다.
  • 그 밖에 운영자에게 전송·수집되는 정보는 없습니다. 운영 서버는 누가 무엇을 검색했는지 알아볼 수 있는 형태로 기록하지 않습니다.
  • 확장은 이용자가 보고 있는 네이버 통합검색·블로그·네이버쇼핑 검색, 쿠팡 검색·상품 화면의 내용을 읽어 요약을 보여 줍니다. 읽은 내용은 이용자의 브라우저 안에서 처리합니다.
  • 이용자가 상품 페이지에서 "리뷰 원문 내려받기"를 누르면, 그 상품의 공개 리뷰를 모아 이용자 기기에 파일(CSV)로 내려받습니다. 확장에 저장하지 않고 운영자에게 보내지 않습니다.
  • 네이버 스마트스토어·브랜드스토어 페이지는 이용자가 설정에서 "사용 설정"을 눌러 브라우저의 권한 창에서 허용했을 때만 읽습니다. 허용하지 않으면 그 사이트에서 아무것도 하지 않습니다.
  • 회원 가입이 없습니다. 이름, 이메일, 전화번호를 받지 않습니다.
  • 네이버·쿠팡 계정의 비밀번호, 로그인 정보, 쿠키를 읽거나 저장하지 않습니다.
  • 이용자가 선택해서 넣는 API 키(네이버 검색광고, NAVER API HUB, OpenAI, Gemini)는 이용자의 브라우저에만 저장되며, 운영자에게 전송되지 않습니다.
  • AI 진단은 이용자가 버튼을 누르고 확인했을 때만, 이용자 본인의 키로 OpenAI·Google에 질문을 보냅니다.
  • 처음 설치하면 안내와 동의 화면이 나오며, 동의하기 전에는 화면 표시와 조회를 하지 않습니다.
  • 이용자의 정보를 판매하지 않고, 광고에 쓰지 않습니다.

2. 확장이 이용자의 기기 안에서 처리하는 것

아래 내용은 이용자의 브라우저 안에서만 처리·저장하며 운영자에게 전송되지 않습니다. 다만 검색어와 임의 식별값은 3절 (마)의 경우에 한해 운영 서버로 전송됩니다.

API 키를 넣지 않아도 30일 검색량·연관 검색어(3절 (마)의 방식), 네이버쇼핑·쿠팡 화면의 상품 분석(리뷰 수, 평점, 배송 유형, 광고 상품 수), 블로그 상위 10개 분석, 수익률 시뮬레이션은 동작합니다.

블로그 상위 글 분석은 화면에 나온 글 주소로 그 글의 페이지를 요청합니다. 받은 페이지는 확장의 메모리에 최대 10분 동안만 두며 저장소에 기록하지 않습니다. 저장되는 요약(평균 글자 수, 사진 수 등)에는 작성자 아이디가 들어가지 않습니다. 확장은 화면에 표시된 다른 사람의 정보(블로그 작성자, 리뷰 작성자 등)를 목록으로 모아 확장 안에 저장하거나 외부로 보내지 않습니다.

다만 이용자가 "리뷰 원문 내려받기"를 누르면, 그 상품 페이지에 누구에게나 공개된 리뷰를 이용자 기기의 파일로 만듭니다. 파일에는 사이트가 일부를 가려 보여 주는 형태의 작성자 계정명이 들어갑니다. 내려받은 파일의 보관과 이용은 이용자의 책임이며, 리뷰의 권리는 작성자와 해당 사이트에 있습니다.

3. 외부로 나가는 요청

확장이 스스로 외부에 보내는 요청은 아래 다섯 가지뿐입니다. (가)~(라)는 이용자의 브라우저가 해당 서비스에 직접 접속하며 운영자를 거치지 않습니다. (마)만 운영 서버를 거칩니다.

구분언제어디로무엇이 나가는가
(가) 블로그 상위 글 분석블로그 검색 상위 글의 글자 수·이미지 수 등을 분석할 때네이버 블로그(해당 글의 페이지)그 글의 주소에 대한 페이지 요청. 로그인 정보(쿠키)를 싣지 않습니다.
(나) 본인 키로 하는 네이버 조회이용자가 설정에 네이버 API 키를 넣은 경우에만(키를 저장할 때의 연결 확인 포함)네이버 검색광고 API, NAVER API HUB조회하려는 검색어, 그리고 인증을 위한 이용자 본인의 키 값
(다) 본인 키로 하는 AI 진단이용자가 AI 키를 넣고, "AI 진단하기"를 눌러 호출 수·예상 비용을 확인한 경우에만(키를 저장할 때의 연결 확인 포함)OpenAI API(ChatGPT), Google Gemini API브랜드·상품명, 카테고리, 경쟁사 이름이 들어간 질문과 그 답변을 분석하는 요청, 그리고 인증을 위한 이용자 본인의 키 값. 네이버에서 받은 자료나 화면 내용은 보내지 않습니다.
(라) 리뷰 원문 내려받기이용자가 쿠팡 또는 네이버 스토어 상품 페이지에서 "리뷰 원문 내려받기"를 눌렀을 때만이용자가 보고 있는 그 사이트(쿠팡, 네이버 스마트스토어·브랜드스토어)그 상품의 리뷰 목록 요청(상품 번호, 쪽 번호). 이용자의 브라우저가 그 사이트를 볼 때와 같은 방식으로 나가며, 그 사이트에 로그인해 있으면 브라우저가 평소처럼 로그인 상태를 함께 보냅니다. 확장은 그 값을 읽거나 저장하지 않습니다.
(마) 키 없이 하는 검색량 조회이용자가 본인 네이버 검색광고 키를 넣지 않았고 설정의 "키 없이 검색량 보기"를 끄지 않은 상태에서, 확장이 검색량을 조회할 때운영 서버(운영자가 Cloudflare의 설비에서 운영) → 네이버 검색광고 API조회하려는 검색어(한 번에 최대 5개), 임의 식별값, 확장 버전. 운영 서버는 운영자의 네이버 검색광고 키로 검색량·연관 검색어·광고 경쟁 정도를 조회해 돌려줍니다. 이용자의 API 키, 화면 내용, 계정 정보, 쿠키는 보내지 않습니다.

(마)는 본인 검색광고 키를 연결하거나 설정에서 "키 없이 검색량 보기"를 끄면 일어나지 않습니다. 운영 서버는 설치 하나당 하루 400회까지 받습니다. (나)·(다)는 이용자가 키를 넣지 않으면 일어나지 않습니다. (라)는 버튼을 누르지 않으면 일어나지 않으며, 최신순 최대 2,000건까지 약 0.4초 간격으로 요청합니다. (다)의 호출 요금은 이용자의 OpenAI·Google 계정에 청구됩니다. 확장은 공급자마다 하루 30건까지만 호출합니다.

(마)에서 운영 서버가 다루는 것은 아래가 전부입니다.

  • 검색어와 그 조회 결과: 같은 검색어를 네이버에 다시 조회하지 않기 위해 최대 24시간 임시 보관한 뒤 지웁니다. 누가 검색했는지(임의 식별값, 접속 IP)와 묶어 저장하지 않습니다.
  • 하루 요청 횟수(숫자): 임의 식별값별, 접속 IP별로 셉니다. 접속 IP는 원문을 저장하지 않고, 날마다 달라지는 알아볼 수 없는 값으로 바꿔 횟수만 셉니다. 이틀이 지나면 지웁니다.
  • 운영 서버의 기록(로그)에 검색어를 남기지 않습니다. 운영자는 검색어를 이용 통계나 마케팅에 쓰지 않습니다.

그 밖에 나가지 않는 것: 이용자가 보고 있는 화면의 전체 내용, 방문한 페이지의 주소 목록, 네이버·쿠팡 계정 정보, 쿠키, 비밀번호, 이름, 이메일, 전화번호.

접속 과정에서 각 서비스가 받는 정보(IP 주소 등)와 (다)에서 OpenAI·Google이 받은 질문의 처리는 각 회사의 개인정보 처리방침과 API 이용 약관을 따릅니다.

4. 처리 목적

  • 이용자가 보고 있는 화면의 공개 수치를 요약해 보여 주기 위해
  • 이용자가 요청한 수치(검색량, 추이 등)를 이용자 본인의 키로 조회해 보여 주기 위해
  • 본인 키가 없는 이용자가 요청한 검색량을 운영자의 키로 대신 조회해 보여 주고, 그 조회가 남용되지 않게 하루 한도를 지키기 위해
  • 이용자가 요청한 AI 진단을 이용자 본인의 키로 실행해 보여 주기 위해
  • 이용자가 요청한 상품 리뷰를 이용자 기기의 파일로 내려받게 하기 위해
  • 같은 조회를 반복하지 않고, 이용자 키의 호출 한도와 요금을 넘지 않게 하기 위해

위 목적 밖으로 쓰지 않습니다. 운영자는 이용 통계를 수집하지 않으며, 운영 서버로 온 검색어를 통계로 만들지 않습니다. 광고를 맞춤 표시하는 데 쓰지 않습니다.

아래 표의 마지막 두 줄(운영 서버) 말고는 모두 이용자의 기기 안에 있는 정보입니다.

  • 외부와의 통신은 암호화된 연결(HTTPS)로 이루어집니다.
  • 네이버 API 주소에 대한 권한은 이용자가 키를 넣을 때에만 요청합니다.
  • 네이버 스마트스토어·브랜드스토어에 대한 권한은 이용자가 설정에서 "사용 설정"을 누를 때에만 요청하며, "사용 해제"로 반납할 수 있습니다.
