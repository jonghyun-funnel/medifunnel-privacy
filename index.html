3. 외부로 나가는 요청

(나) 본인 키로 하는 조회 이용자가 설정에 API 키를 넣은 경우에만(키를 저장할 때의 연결 확인 포함) 네이버 검색광고 API, NAVER API HUB 조회하려는 검색어, 치과 이름(지역 이름을 붙인 형태 포함), 그리고 인증을 위한 이용자 본인의 키 값

그 밖에 나가지 않는 것:

  • 이용자가 보고 있는 화면의 전체 내용
  • 방문한 페이지의 주소 목록
  • 네이버 계정 정보, 쿠키, 비밀번호

확장은 외부 AI 서비스(LLM 등)를 호출하지 않으며, 그런 서비스로 데이터를 보내지 않습니다.

접속 과정에서 네이버가 받는 정보(IP 주소 등)의 처리는 네이버의 개인정보 처리방침을 따릅니다.
